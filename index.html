Forensic Algorithms

Six independent analysis engines working in concert to catch digital manipulation

Error Level Analysis (ELA)

Detects JPEG re-compression by amplifying differences in compression ratios. Tampered regions appear as bright anomalies on the ELA map.

JPEGCompression

Noise Inconsistency

Analyzes pixel-level noise patterns. Copy-pasted or AI-generated regions have different noise signatures than the surrounding authentic content.

Pixel AnalysisStatistical

Clone Region Detection

Identifies copy-cloned regions using block-matching heuristics. Detects duplicated stamp areas, cloned signatures, and repeated textures.

Copy DetectionHeuristic

Metadata Analysis

Reads embedded file metadata to detect software editing signatures, date anomalies, missing authentic camera data, and suspicious GPS inconsistencies.

EXIFFile Headers

Edge Sharpness Analysis

Detects inconsistent blur and sharpness transitions. A genuine scan has uniform focal characteristics; pasted elements often have mismatched edges.

Edge DetectionGradient

DCT Frequency Artifacts

Analyzes DCT coefficient distributions in 8×8 blocks. Edited regions often leave detectable frequency-domain footprints that differ from the original capture.

Frequency DomainDCT
